# Playwright agent rules and hints

## building and review

- check https://playwright.dev/docs/best-practices for references and save as good/bad shortlist
- check https://playwright.dev/docs/release-notes in case package upgrade
- use KISS principles
- you can add testid for new elements if needed

## run

- ask before local run
- firstly test new/changed tests ‘npx playwright test —-only-changed’
